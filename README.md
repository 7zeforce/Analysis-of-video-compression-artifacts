# Analysis-of-video-compression-artifacts

The project analyzes artifacts in compressed videos. It uses a bitrate of two megabits per second to compress the video. Next, it creates graphics from the derivative errors in a single frame of the video before and after compression.

## Docker

Все команды выполняются из папки `AnalysisApplication`, где лежит `docker-compose.yml`.

```bash
docker compose up -d --build
```

Приложение поднимется на http://localhost:8080. HTTPS в контейнере не настроен, поэтому открывать нужно именно `http://`.

Остановить:

```bash
docker compose down
```

Образ основан на `mcr.microsoft.com/dotnet/aspnet:10.0`, в него дополнительно ставятся `ffmpeg` и `libatomic1` — последний нужен нативной библиотеке OpenCvSharp, без него анализ падает с ошибкой инициализации `OpenCvSharp.Internal.NativeMethods`.

Compose монтирует `./uploads` в `/app/wwwroot/videos`, так что загруженные и обработанные видео остаются на диске между перезапусками контейнера.

## Запуск без Docker

Из папки `AnalysisApplication`:

```bash
dotnet run
```

По умолчанию поднимется профиль `http` на http://localhost:5130. Профиль с HTTPS запускается как `dotnet run --launch-profile https`, он слушает https://localhost:7227 и http://localhost:5130.

База данных SQLite создаётся автоматически при первом запуске рядом с собранным приложением (`Data/app.db`), миграции применяются на старте.

## Как пользоваться

1. Открыть страницу и загрузить видео кнопкой «Заменить видео» или перетаскиванием файла. Поддерживаются mp4, webm, ogg, mov, mkv, avi, wmv; всё, кроме mp4 и webm, конвертируется в mp4 на сервере.
2. Нажать «Сжать и оценить». Приложение сожмёт видео до 2 Мбит/с, а затем покадрово сравнит копию с оригиналом.
3. В карточке результатов появятся сводные метрики по Y, Cr, Cb и кадр с максимальной ошибкой с таймкодом. Кнопка «Перейти к кадру» перематывает оба плеера на это место.
4. В карточке графика выбирается критерий (MAE, MSE, PSNR, максимальная разность), масштаб оси Y (авто, от нуля, логарифмический), подписи оси X (время или номера кадров) и диапазон кадров. Кнопка «Скачать график» сохраняет картинку в PNG или JPEG с увеличением до 3×.
5. В карточке «Видео с артефактами» выбирается режим и коэффициент усиления, кнопка «Авто» подставляет значение, рассчитанное как `255 / DiffMax` по результатам анализа. Готовый ролик можно посмотреть на странице и скачать.

### Режимы визуализации артефактов

| Режим | Что показывает |
| --- | --- |
| чёрный фон, модуль разности | артефакты светятся на чёрном, самый наглядный вариант |
| серый фон, со знаком разности | светлее середины — кодек завысил яркость, темнее — занизил |
| тепловая карта | псевдоцвет: слабые ошибки синие, сильные красные |

Усиление необходимо потому, что в чистом виде разность почти не видна: средняя яркость кадра разности держится около одного уровня из 255.

## API

Все ответы в JSON, поле `ok` сообщает об успехе. Долгие операции возвращают `jobId`, по которому опрашивается статус.

| Метод и маршрут | Назначение |
| --- | --- |
| `POST /Video/Upload` | загрузка файла (multipart, поле `file`) |
| `GET /Video/List` | список видео |
| `POST /Video/Delete?id=` | удаление видео вместе со сжатыми копиями |
| `POST /Video/Compress?id=&bitrate=2000` | сжатие до указанного битрейта |
| `POST /Estimation/Start?id=` | запуск анализа сжатой копии |
| `GET /Estimation/Status?jobId=&points=2000` | прогресс и результаты анализа |
| `POST /Artifacts/Start?id=&gain=&mode=` | сборка видео с артефактами (`gray`, `signed`, `heat`) |
| `GET /Artifacts/Status?jobId=` | прогресс сборки и ссылка на готовый файл |

##  Использованные генеративные инструменты

При подготовке учебного проекта использовался ChatGPT (GPT-5.6 Luna) для генерации и редактирования исходного кода, структуры проекта и текста README. Встроенные методы OpenCV и FFmpeg являются обычными алгоритмическими инструментами и не относятся к генеративным моделям.
